# 操作路線

1. 開啟 `/`，依車型與預算篩選。搜尋 `AS-102`、`2023` 或 `suv`；清除篩選後恢復三台種子車源。
2. 收藏一台車，切換收藏篩選。重新整理後收藏仍保留。
3. 選取兩台「加入比較」，查看售價、年份、里程等對照；最多三台。
4. 開啟車源詳情，點選「詢問這台車」。填入測試稱呼與 `visitor@example.com`，儲存本機詢問。
5. 進入右上「車源管理」，切換詢問管理，將該筆標記已聯絡再結案。展開處理紀錄；重新整理後仍保留，結案不能重開。
6. 篩選詢問狀態，匯出 CSV。只會匯出目前篩選的詢問。
7. 車源管理編輯售價或標記洽談中，返回前台檢查。將車源標記已售出後，它將從前台與詢問選單隱藏。
8. 新增一台車源，填寫名稱、價格、里程、描述並選擇示意圖片。儲存後即可在前台查看。
9. 輸入零利率測試月付。自備款超過車價時會提示錯誤。
10. 切換 English，前台與管理頁均可使用。售車需求僅產生預覽，不送出或保存。

所有操作僅影響目前瀏覽器。沒有實際詢問信件、預約或金融交易。請使用測試資料。
